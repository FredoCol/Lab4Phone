# Indicateurs Lab4Phone

Les bases opérationnelles d'indicateurs ne sont pas distribuées dans
ce dépôt.

Le format CSV attendu est :

    category,type,match,value,severity,notes

Description :

- category : famille ou catégorie de menace ;
- type : package, pattern, domain ou autre type compatible ;
- match : plateforme ciblée, par exemple android ou ios ;
- value : valeur recherchée ;
- severity : score numérique ;
- notes : origine ou explication.

Le fichier example.csv contient uniquement des valeurs fictives.
